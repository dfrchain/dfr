# Security Policy

## Scope
This public repository is a developer/testnet distribution, not a guarantee of production fitness or an independent security audit. The publication of code is not approval for use with real customer funds.

## Private reporting
Email **hello@dfrchain.com** with the affected component, a minimal reproduction, and impact. Do not include live secrets or private customer data in the email or a public issue. Public GitHub issues are appropriate for non-sensitive documentation and usability problems.

## Credential exposure
If you believe a key or other credential was publicly committed, revoke and rotate it immediately in the relevant system. Deleting a file, changing visibility, or force-pushing Git history does not invalidate an exposed credential.

## Supported versions
Only the repository's current maintained branch is considered for triage; no security support or response-time guarantee is asserted here.
